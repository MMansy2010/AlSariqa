# ملفات الصوت

الملفات الافتراضية (`*.wav`) مُولَّدة تلقائياً. يمكنك استبدالها بملفات أعلى جودة **بنفس الأسماء**:

| الملف | الاستخدام |
|--------|-----------|
| `scream.wav` | jumpscare الفريق الأزرق |
| `laugh.wav` | jumpscare الفريق الأحمر |
| `static.wav` | تشويش فخ الـ System Crash |
| `cheer.wav` | زغاريد فخ الفوز المزيف |

يمكن أيضاً استخدام `.mp3` بتعديل المسارات في `game-audio.js`.
